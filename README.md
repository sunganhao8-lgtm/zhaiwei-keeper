# 宅卫 · 空置房管家 🏡

> 空着的房子，有人替你看着 —— 定期巡检 · 打卡留痕 · 电子报告 · 异常即报

宅域（Zhaiyu）旗下第二款 C 端产品（第一款是[宅咪打卡](../zhaimi-checkin)）。面向"人房分离"的有房人群：

- **候鸟旅居**：海南/云南的房子，人走了房就空，一空半年（仅三亚候鸟老人 38 万）
- **异地多房**：一线城市打拼，老家/二线城市有房空着
- **海外华侨**：人在海外，国内房产完全无法照看

**参考模式（海外已验证）**：美国 Home Watch 行业（NHWA 协会 + 认证 + 专用巡检软件，单次 $45-65 ≈ 300-450 元）、日本空き家管理（月费 5000-10000 日元 ≈ 250-500 元/月）。国内空置房 6500-9000 万套、至今无全国性品牌。

## 产品逻辑

```
业主订阅套餐（299 元/月起，对标美日 300-500 元）
   ↓
管家按周期上门（每周1次 / 每月2次 / 每月1次）
   ↓
到店打卡（定位+时间戳）→ 检查项逐项 ✓/⚠ → 现场拍照
   ↓
生成电子报告卡（3:4，可发微信家人群）→ 异常自动附处置建议
   ↓
"一切安好"的安心感 → 续费 → 多套房加购
```

留痕体系（打卡/拍照/定位/报告）就是产品的信任壁垒，对应最大的风险：把家门交给陌生人。

## 当前功能（MVP · 纯前端）

- **双角色**：业主端（房源/巡检计划/报告/超期告警）· 管家端（任务列表/到店打卡/巡检执行）
- **巡检周期**：每周1次/每月2次/每月1次，自动算下次、超期红字（复用宅咪打卡周期任务逻辑）
- **检查项标准库 14 项**：通用 10 项（通风/渗漏/马桶补水/水电表/霉斑/门窗/信箱/温湿度/绿植/防盗）+ 场景附加（候鸟：防台风、除湿机；异地：空调试机；海外：视频连线巡检）
- **异常状态机**：任一项 ⚠ → 整单标记异常，自动附处置建议（如渗漏→先关总阀再报修）
- **到店打卡**：尝试 GPS 定位 + 手动备注兜底（http 局域网无定位权限）
- **现场照片**：最多 4 张，自动压缩至 480px
- **报告分享卡**：1080×1440 Canvas，米白底 + 墨绿 + 异常红，长按保存发微信
- 演示模式：URL 加 `?demo=1`（三亚候鸟房 + 成都异地房，含超期 10 天、历史霉斑异常样本）
- 数据导出/导入 JSON（不锁用户数据）
- **PWA 可安装**：manifest + Service Worker，添加到主屏幕后全屏离线可用

## 冷启动清单（10 个种子业主怎么来）

1. **候鸟场景**：三亚/海口候鸟社区与业主微信群，候鸟季前（9-10 月）进群；与物业谈"空置房看护"合作分成
2. **异地场景**：高端小区物业 BD（物业最清楚哪套房常年空着）；小红书发"空房管家"内容（该话题下已有零星供给，说明需求存在）
3. **海外场景**：移民/留学机构转介，"人在国外国内房子没人管"是社群刚需话题
4. **供给端**：家政阿姨/物业客服做兼职巡检员，按片区排线，一次上门 30-40 分钟

## 风险红线（入室信任 = 生死线）

- 双人上门、全程时间戳留痕、每项检查拍照存证
- 巡检员背景审查 + 家财险兜底（第二阶段必做，报告卡先行建立信任）
- 智能锁临时密码授权，不碰实体钥匙
- 一次失窃/纠纷足以杀死品牌——宁可不接单
